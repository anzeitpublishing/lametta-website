# Dateiablage für die LAMETTA!-Website

Hier können neue Dateien dauerhaft für die Website abgelegt werden:

- `fonts/`: Web-Schriften, möglichst als `.woff2` oder `.woff`
- `logos/lametta/`: LAMETTA!-Logo und weitere eigene Markenlogos, möglichst als `.svg`
- `logos/partners/`: freigegebene Logos ehemaliger oder aktueller Partner
- `images/`: Fotos, Banner, Cover und weitere Bilddateien
- `documents/`: Mediadaten, Styleguides und andere PDF-Dokumente

Bitte möglichst aussagekräftige Dateinamen ohne Umlaute oder Leerzeichen verwenden, zum Beispiel `lametta-logo-rot.svg` oder `partnername-logo.svg`.

Schriften sollten nur abgelegt und auf der Website verwendet werden, wenn eine passende Webfont-Lizenz vorliegt. Partnerlogos sollten für die öffentliche Referenznennung freigegeben sein.
